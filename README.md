# Europe 2026 — تحديث التطبيق
تطبيق ويب عربي (PWA) لإدارة خطة 21 أكتوبر إلى 5 نوفمبر 2026.

## التثبيت
ارفع ملفات `index.html`, `app.js`, `manifest.webmanifest`, `sw.js` إلى جذر المستودع نفسه، مع الإبقاء على الصور والأيقونات الموجودة فيه. فعّل GitHub Pages من Settings > Pages على فرع main /root إن لم تكن مفعلة.

## مهم
البيانات الشخصية والحجوزات تُحفظ في LocalStorage محليًا. النسخ الاحتياطية JSON قد تتضمن بيانات حساسة، فلا ترفعها إلى GitHub. لا يتضمن التطبيق ملفات PDF/QR الأصلية ولا يتتبع الموقع في الخلفية؛ وظيفة GPS تتحقق عند الضغط فقط. إذا كانت لديك بيانات سابقة في التطبيق، صدّر نسخة JSON قبل التحديث.
